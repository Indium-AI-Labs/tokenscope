# Agent Instructions

## Git and Devlog Rules

- Do not push to GitHub unless and until the user asks.
- If the user asks to push, push to `main`. Do not create pull requests or different branches unless the user explicitly overrides this rule.
- When asked to write a devlog, create or use a folder named `devlogs`, ensure it is listed in `.gitignore`, and write numbered Markdown entries there.
- The first devlog is `devlogs/1.md`, the second is `devlogs/2.md`, and so on.
- Ignore any existing `.txt` devlog file except to understand the last devlog number. Continue with Markdown entries such as `devlogs/3.md`, `devlogs/4.md`, and so on.
